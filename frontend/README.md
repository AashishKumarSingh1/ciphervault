# CipherVault Frontend

A modern cybersecurity dashboard interface for **CipherVault — AES-256 Secure Database Management System**.

## Stack
- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS (Deep Navy & Amber theme)
- **Icons:** Lucide React
- **Data Visualization:** Recharts

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
